# Artwork

The room backgrounds, six-object atlas, and launcher icon were made for Room Reset with the built-in ChatGPT image generation tool. The game ships local copies and needs no image service at runtime. The launcher sizes are resampled versions of the same icon. The room backgrounds use WebP, and the atlas preserves the generated alpha channel.
